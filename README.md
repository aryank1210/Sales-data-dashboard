# Sales Data Dashboard — Power BI

An interactive sales performance dashboard built in Power BI to track revenue, unit sales, and performance trends across products, employees, and time.

## 📊 Overview

This dashboard gives sales stakeholders a consolidated view of revenue performance to identify top-performing products, employees, and monthly trends.

## 🔑 Key Metrics & Insights

- **Total Revenue:** 96.62M | **Total Units Sold:** 1.12M
- **Revenue by Product:** Top performers include Product-7 (5.9M), Product-27 (5.5M), and Product-15 (5.2M)
- **Revenue by Employee:** Even distribution of ~5M revenue across top employees (EMP-4, EMP-9, EMP-3, EMP-18, EMP-15)
- **Revenue Trend by Month:** Tracked monthly revenue from January to April, revealing a declining trend into April (28.0M → 24.2M → 27.1M → 17.3M)

## 🛠️ Tools & Techniques

- **Power BI Desktop** — data modeling and interactive visualizations
- **Power Query** — data cleaning and transformation
- Visuals used: KPI cards, bar charts, line charts, and interactive slicers (Date, Product Name, EMP Name, Supervisor)
